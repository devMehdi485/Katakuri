# Contribuer

1. Expliquer la source et le niveau de confiance de chaque nouvel indicateur, sans données personnelles.
2. Ne pas ajouter d'échantillon, secret, URL de webhook avec jeton ou mécanisme d'exécution du malware.
3. Garder les lectures locales, les erreurs visibles et les rapports sans contenu sensible.
4. Ajouter un test bénin pour tout comportement modifié ; vérifier Windows PowerShell 5.1 et PowerShell 7.
5. Ne pas rendre les résultats « aucun indicateur » équivalents à « ordinateur sain ».

Avant publication, vérifier `git status` et les fichiers indexés. Ne pas utiliser `git add` sur le dossier parent qui contient vos rapports personnels.
